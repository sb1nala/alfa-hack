# Моки внешних сервисов

Локальные заглушки БКИ, ЕГРЮЛ/ЕГРИП и ФНС «Прозрачный бизнес». Отвечают синтетическими данными из [`seed/companies.json`](../seed/companies.json); реальные сервисы и данные не используются. Задача #19.

## API

Swagger: http://localhost:8001/docs после `docker compose up`.

| Запрос | Ответ |
| --- | --- |
| `GET /egrul/{inn}` | `inn`, `name`, `legal_form` + объект `mocks.egrul` компании: статус, дата регистрации, ОКВЭД, адрес, руководитель |
| `GET /pb/{inn}` | `inn` + `mocks.pb`: выручка, расходы, численность, налоговый долг, массовый адрес, дисквалификация руководителя |
| `GET /bki/report?inn=…` | `inn` + `mocks.bki`: кредиты с платежами и текущей просрочкой, просрочки за 24 мес., запросы за 30 дней |
| `GET /health` | `{"status": "ok", "companies": 9}` |
| `POST /admin/reset` | Сбросить счётчики сбоев, чтобы показать сбой БКИ ещё раз |

- **Неизвестный ИНН** → `404 {"code": "not_found"}`; ИНН не из 10 или 12 цифр → `422`.
- **Формат ответов** совпадает с входами `decide()`: `EgrulReport.from_dict`, `PbReport.from_dict`, `BkiReport.from_dict` из `backend/app/decision/` разбирают тело ответа без адаптеров. Деньги — строки рублей с двумя знаками.
- **Ответ ЕГРЮЛ** подходит для автозаполнения анкеты по ИНН: название, форма, адрес, ОКВЭД, дата регистрации.

## Сбои

`mock_behavior` компании в `seed/companies.json` задаёт сбои по сервису: `fail_first_n` — сколько первых запросов вернут ошибку, `status_code` (по умолчанию 503), `delay_ms` — задержка. Сейчас сбой есть у `demo-bki`: первые 2 запроса к БКИ → 503, дальше нормальный ответ. Счётчики живут в памяти и сбрасываются при перезапуске или через `POST /admin/reset`.

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `MOCKS_PORT` | `8001` | Порт на хосте |
| `MOCKS_LATENCY_MS` | `300` | Задержка каждого ответа, мс — этап «Проверяем данные» виден в демо |
| `MOCKS_SEED_PATH` | `/app/data/companies.json` в образе | Путь к данным; в образ файл копируется из `seed/` при сборке |

## Разработка

```bash
cd mocks
uv sync --locked
uv run pytest
uv run uvicorn app.main:app --port 8001
```

Без Docker данные читаются из `../seed/companies.json`.
