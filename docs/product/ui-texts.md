Версия 0.1.0 · владелец: Продукт · задача #26

Источник истины — [`ui-texts.ru.json`](ui-texts.ru.json): фронтенд берёт тексты по ключам оттуда. Этот файл — читаемая версия для команды и жюри.

**Правила:** обращение на «Вы» с заглавной; без банковского жаргона, термины поясняем при первом упоминании; у каждого статуса есть «что происходит» и «что дальше»; отказ всегда с причиной и советом. Плейсхолдеры — `{name}`.

**Словари кодов** (`products`, `purposes`, `rejectionReasons`, `counterOfferReasons`, `requiredDocuments`) — общий контракт: риски возвращают эти `code` в `Reason.code` и `RequiredDocument.code`, бэкенд — в `Product.code`. Новый код = сначала строка здесь.

## Причины отказа

> Code в Reason.code для исхода REJECTED. message — что случилось, advice — что можно сделать. Внутренние пороги и баллы клиенту не показываем.

| code | Что случилось | Что можно сделать |
| --- | --- | --- |
| `company_liquidating` | По данным ЕГРЮЛ компания находится в процессе ликвидации или реорганизации. | Мы сможем рассмотреть заявку, когда статус компании в реестре станет «Действующая». |
| `director_disqualified` | Руководитель компании числится в реестре дисквалифицированных лиц ФНС. | Если сведения устарели, обратитесь в налоговую службу для их исправления, а затем подайте заявку снова. |
| `overdue_90_plus` | В кредитной истории компании есть просрочка платежей больше 90 дней. | Погасите просроченную задолженность. После обновления кредитной истории заявку можно подать снова. |
| `business_too_young` | Компания зарегистрирована меньше 3 месяцев назад. | Подайте заявку, когда бизнесу исполнится 3 месяца. |
| `tax_debt` | По данным ФНС у компании есть задолженность по налогам. | Погасите задолженность. Когда данные ФНС обновятся, заявку можно подать снова. |
| `high_debt_load` | Платежи по текущим кредитам вместе с новым займут слишком большую часть выручки. | Попробуйте запросить меньшую сумму или погасить часть текущих кредитов. |
| `insufficient_revenue` | Запрошенная сумма слишком велика по сравнению с выручкой компании. | Попробуйте запросить меньшую сумму. |
| `high_risk` | По совокупности данных о компании риск оказался выше, чем мы можем принять сейчас. | Можно подать новую заявку через 3 месяца или на меньшую сумму. |
