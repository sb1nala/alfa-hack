# Цвета интерфейса

Статус: **утверждено продуктом 21.10** · владелец: Продукт · для фронтенда (#11, #13, #14, #44)

Основа палитры — бордо и яркий тиффани. Тема только светлая. Шкалы оттенков построены в OKLCH с шагами как в Tailwind (50–950). Контраст текста везде не ниже WCAG AA (4.5:1).

## Роли цветов

| Роль | Цвет | Где используем |
| --- | --- | --- |
| **Бренд / основное действие** | бордо `#800020` | Одна главная кнопка на экране («Отправить заявку», «Принять условия», «Подписать»), логотип, пройденные шаги таймлайна |
| **Акцент** | тиффани `#0ABAB5` | Текущий шаг таймлайна, вторичная яркая кнопка («Подобрать кредит»), выделение выбранной цели или продукта, исход «Одобрено» |
| **Ссылки** | тиффани-600 `#00716E` | Текстовые ссылки и иконки цвета тиффани на белом |
| **Текст** | графит `#211E23`, вторичный `#5F5C63` | Основной и поясняющий текст |
| **Фон страницы** | `#F7F3FA` | Фон приложения. Карточки — белые `#FFFFFF` |
| **Границы** | `#D3CFD7` | Разделители, рамки полей |

Правила:

- **Бордо — только для действий и бренда.** Отказ и ошибки красим красным (`red`), он смещён к оранжевому и не путается с основной кнопкой.
- **На тиффани пишем только тёмным** (`#1C1A1E`, контраст 7.2:1). Белый текст на тиффани не проходит контраст (2.4:1).
- **Цвет не единственный носитель смысла.** У каждого исхода есть иконка и заголовок, это важно для людей с нарушением цветовосприятия.

## Исходы и статусы

Карточка решения: фон — светлый оттенок, заголовок — тёмный оттенок, подпись — средний оттенок того же цвета.

| Исход / статусы | Цвет | Фон | Заголовок | Подпись | Иконка (Material Icons) |
| --- | --- | --- | --- | --- | --- |
| `APPROVED`, `OFFER_ACCEPTED`, `SIGNED`, `ISSUED` | тиффани | `#DBFEFC` | `#004240` | `#00716E` | `CheckCircleOutline` |
| `COUNTER_OFFER` | янтарь | `#FFF3D3` | `#592000` | `#733500` | `SwapHoriz` |
| `NEEDS_INFO`, `MANUAL_REVIEW` | синий | `#E6F7FF` | `#032483` | `#2654BF` | `UploadFile` / `PersonSearch` |
| `REJECTED` | красный | `#FFE9E0` | `#730000` | `#B01000` | `HighlightOff` |
| `DRAFT`, `SUBMITTED`, `CHECKING`, `SCORING`, `CANCELLED` | нейтральный | `#F8F6F9` | `#211E23` | `#5F5C63` | `HourglassEmpty` / `Close` |

Таймлайн: пройденные шаги — бордо, текущий — тиффани с кольцом `#DBFEFC`, будущие — контур `#B6B2BA`, остановленный (`REJECTED`, `CANCELLED`) — `#97939B`.

Чипы статусов в кабинете аналитика — те же пары «фон + заголовок».

### Классы риска

Класс риска в кабинете аналитика — чип с той же логикой «чем хуже, тем тревожнее». Тиффани только для хороших классов: позитивный цвет на рискованном классе вводит в заблуждение.

| Класс | Смысл | Фон | Текст | MUI `color` |
| --- | --- | --- | --- | --- |
| A, B | Низкий риск | `#DBFEFC` | `#004240` | `success` |
| C | Средний | `#F8F6F9` | `#211E23` | `default` |
| D | Серая зона, ручная проверка | `#FFF3D3` | `#592000` | `warning` |
| E | Высокий риск | `#FFE9E0` | `#730000` | `error` |

### Текст цвета тиффани

Контурные чипы и текст цвета `secondary` на белом берут `secondary.dark` `#00716E` (5.9:1), а не `secondary.main` `#0ABAB5` (2.4:1 — не проходит AA). В MUI: `<Chip variant="outlined" sx={{ color: 'secondary.dark', borderColor: 'secondary.main' }} />`.

## Тема MUI

Скопировать в `frontend/src/theme.ts`:

```ts
import { createTheme } from "@mui/material/styles";

export const theme = createTheme({
  palette: {
    mode: "light",
    primary: { main: "#800020", dark: "#670015", light: "#A02F3B", contrastText: "#FFFFFF" },
    secondary: { main: "#0ABAB5", dark: "#00716E", light: "#4CCAC5", contrastText: "#1C1A1E" },
    success: { main: "#00716E", dark: "#004240", light: "#DBFEFC", contrastText: "#FFFFFF" },
    warning: { main: "#F2A900", dark: "#733500", light: "#FFF3D3", contrastText: "#1C1A1E" },
    info: { main: "#2654BF", dark: "#032483", light: "#E6F7FF", contrastText: "#FFFFFF" },
    error: { main: "#B01000", dark: "#730000", light: "#FFE9E0", contrastText: "#FFFFFF" },
    text: { primary: "#211E23", secondary: "#5F5C63", disabled: "#97939B" },
    divider: "#D3CFD7",
    background: { default: "#F7F3FA", paper: "#FFFFFF" },
    grey: {
      50: "#F7F3FA", 100: "#EAE6ED", 200: "#D3CFD7", 300: "#B6B2BA", 400: "#97939B",
      500: "#79757D", 600: "#5F5C63", 700: "#49464D", 800: "#343138", 900: "#211E23",
    },
  },
  shape: { borderRadius: 8 },
  typography: { button: { textTransform: "none", fontWeight: 500 } },
  components: {
    MuiLink: { defaultProps: { color: "secondary.dark" } },
    MuiButton: { defaultProps: { disableElevation: true } },
  },
});
```

Для `Alert` и чипов исходов используйте `severity` / `color`: `success` → одобрено, `warning` → контрпредложение, `info` → нужны данные и ручная проверка, `error` → отказ. Светлый фон берётся из `palette.<color>.light`.

| Ссылка `#00716E` на белом | 5.9:1 | AA |
| Вторичный текст `#5F5C63` на белом | 6.6:1 | AA |
