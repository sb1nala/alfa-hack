## Сценарии с продолжением

- **`demo-info` после запроса данных.** Клиент исправляет выручку на 9 400 000 ₽ (расхождение с ФНС ≤ 30%) → `CHECKING` → `SCORING` → `APPROVED` 3 млн / 24 мес. / 26,0%, класс A (150). Если клиент оставит 18 млн, но приложит `bank_statement_12m`, → `MANUAL_REVIEW` (`revenue_mismatch_review`).
- **`demo-manual` у аналитика.** Аналитик открывает заявку из очереди и выносит любое из четырёх решений; ожидание для демо — `COUNTER_OFFER` или `APPROVED` с обоснованием.
- **`demo-term`, `demo-amount`, `demo-product`.** Клиент принимает предложение → `OFFER_ACCEPTED` → `SIGNED` → `ISSUED`; или отказывается → `CANCELLED`.

## Поведение моков

`mock_behavior` в `seed/companies.json` описывает сбои. Сейчас один: для `demo-bki` — `{"bki": {"fail_first_n": 2, "status_code": 503}}`. Первые два запроса к БКИ по этому ИНН возвращают 503, третий — нормальный ответ. Счётчик сбрасывается при перезапуске мока.
