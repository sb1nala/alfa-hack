## Как работаем

- В `main` — только через PR; каждый PR смотрит один человек из команды.
- Контракт фронт ↔ бэк — только `docs/openapi.yaml`.
- `AGENTS.md` (Codex) и `CLAUDE.md` (Claude Code) — общие правила для ИИ, чтобы все писали код в одном стиле.
- Утром 15-минутный созвон: что сделал, что делаю, где застрял.
- Каждый вечер в 21:00 — слияние готового и `docker compose up` с нуля на машине, где никто не разрабатывал.

## Стартовые промпты

**Бэкенд → Codex**

```text
Репо sb1nala/alfa-hack — хакатон Alfa Hack, «Умный кредитный кабинет предпринимателя». Прочитай AGENTS.md и docs/.
Стек: Python 3.12, FastAPI, SQLAlchemy 2 (async), Alembic, PostgreSQL 16, uv (uv.lock), pytest.
Сделай каркас backend/ и docker-compose.yml (сервисы db, backend, worker; mocks и frontend добавим позже).
Статусы и переходы — строго по docs/application-states.md.
Модели: users, companies, products, applications, application_events, decisions, offers, documents.
Эндпоинты-заглушки для клиента и андеррайтера и скрипт выгрузки docs/openapi.yaml.
Сначала предложи план и список эндпоинтов, потом пиши код. Никаких платных сервисов.
```

**Фронтенд → Codex**

```text
В репо sb1nala/alfa-hack создай frontend/: Vite + React 18 + TypeScript, pnpm, React Router, TanStack Query, MUI.
Два раздела: /client (кабинет предпринимателя) и /bank (кабинет кредитного аналитика), вход по логину/паролю, JWT в памяти.
Экраны клиента: подбор продукта по цели, анкета (ИНН → автозаполнение), статус-таймлайн, решение.
Типы API генерируй из docs/openapi.yaml через openapi-typescript. Статус заявки слушай через EventSource.
Добавь Dockerfile (multi-stage, nginx с прокси /api → http://backend:8000). Тексты — на русском, без банковского жаргона.
```

**Риски и данные → ChatGPT**

```text
Я делаю упрощённую, но честную кредитную политику для кредитования МСП (ООО и ИП) в прототипе для хакатона.
Источники данных: анкета (сумма, срок, цель, выручка), БКИ (долги, платежи, просрочки),
ЕГРЮЛ/ЕГРИП (статус, дата регистрации, ОКВЭД, руководитель), ФНС «Прозрачный бизнес» (налоговые долги, численность, массовый адрес).
Составь: 1) стоп-факторы; 2) балльную скоркарту на 8–10 признаков с интервалами и баллами; 3) классы риска A–E;
4) матрицу решения с 5 исходами, включая контрпредложение через DSCR ≥ 1,2; 5) 8 синтетических компаний с валидными ИНН,
покрывающих все исходы. Объясни каждое правило одной строкой — это увидит жюри.
```

**Продукт → Claude (режим Research)**

```text
Исследуй кредитование малого и микробизнеса в России в 2025–2026: какие продукты предлагают Альфа-Банк, Сбер, Т-Банк, Точка, Модульбанк;
как выглядит онлайн-заявка (какие поля, какие документы, срок решения); что предприниматели называют болями
(отзывы, интервью, обзоры ЦБ); какие данные банк берёт из БКИ, ЕГРЮЛ, «Прозрачного бизнеса» и ГИР БО.
Итог: таблица продуктов, список из 10 болей с источниками, 3–4 Jobs-to-be-Done и выводы для MVP кредитного кабинета.
```

Совет по Claude Pro: лимиты считаются окнами по 5 часов — длинные исследования ставить в начало окна. Совет по Codex: одна задача — один PR, так проще ревьюить.
